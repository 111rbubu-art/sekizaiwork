# 戒名彫刻のご確認（お客様用ページ）

郵送の 往復を 片道に するため、お客様が スマホで 彫刻原稿を 確かめて 回答する ページ。
手紙の QR コード・URL、または LINE で お客様ごとの URL を 送る。

## 画面の 流れ（index.html）
1. ご本人の 確認：登録電話の 種類と 市外局番を ヒントに 出し、どちらかの 番号の 下 4 桁・お名前・続柄
2. お墓の 確認：お墓の 写真・墓地・区画・お墓の 名前。違えば 店の 電話を 出して 電話を 受け付ける
3. 文字と 場所：彫刻する 場所の 写真（赤い 印。側面の 1 行目など 拓本と 違う 面に 彫ることが あるため 別に 出す）と、拓本を 参考に 校正した JPEG 1 枚を 幅いっぱいに。最後まで 見ると 回答ボタンが 押せる
4. 回答：承諾（チェック・指の サイン）／修正（写真に 印・文字・紙の 写真・電話）

## 段階
- 段階 2：画面の 試作（`?t=` なしで 開くと 今も 見本で 動く。回答は 送らない）
- 段階 3：さくらの PHP。お客様ごとの 推測できない URL（`?t=<32 文字>`）、本人確認、閲覧・回答の 記録、回答後は 締め切り
- 段階 4（いま）：業務アプリ（index_b.html v1.9.539〜）の 納骨・戒切の 詳細、リンクバーの［📨 お客様確認］
  - 初めて 押すと upload.php の URL と 合言葉（`.htsecret` と 同じ）を 聞く。［⚙ 接続設定］で 店の電話・受付時間も 変えられる（既定 0120-333-845／午前8時〜午後5時）。
    設定は localStorage `kakuninCfg` と SP の 設定ファイル（`kakunin_cfg_shared_v1`）に 入り、ほかの 端末にも 写る
  - 作る：お寺・お墓の名前（○○家）・施主・原稿の版（資料結果の 再提出①②や 前の 訂正から 決める）・電話番号（案件の 電話番号を 分けて 入れる）、
    写真 3 枚（案件フォルダー 1 階層下まで と SP 添付の 画像。確認資料は 名前に「確認資料」の いちばん新しいもの を 先に 選ぶ。［💻 パソコンから］も）。
    写真は 長い辺 2000px、確認資料は 縮めず さくらの 上限を 超えるときだけ 落とす
  - URL の コピー・QR コード（cdnjs の qrcodejs 1.0.0）・QR の PNG 保存（お手紙用）・LINE 用の 文
  - 一覧：状態（まだ開いていない／開いた／本人確認済／最後まで見た／承諾・訂正あり・お墓が違う／期限切れ／停止）、回答と 記録を 見る
  - 取り込む：案件フォルダーの `お客様確認/` に `YYYYMMDD_初回(修正N)_回答_承諾.txt`（読める まとめと 記録）・`回答記録.json`・`お客様に見せた原稿.jpg`・`原稿に印.jpg`・`お客様の写真N.jpg`。
    そのあと さくらから 消すか 聞く

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | お客様の 画面。`?t=` が あれば `api.php` と やりとり |
| `api.php` | お客様側の 受け口（hint・verify・img・seen・answer）。同じ オリジンなので 合言葉 なし。鍵は 本人確認の 後に 出す |
| `upload.php` | 店側の 受け口（create・status・list・getfile・delete）。合言葉（`.htsecret`）＋ CORS |
| `lib.php` | 共通（直接は 開かせない） |
| `data/` | お客様ごとの フォルダー（`.htaccess` で 外から 読めない）。リポジトリには 入れない |

## 記録（証拠）
- `log.json`：作成・開いた・本人確認（合う／合わない と 入れた 4 桁）・最後まで 見た・回答。どれも 日時・IP・端末
- `answer.json`：回答（ok／ng／grave_ng）・お名前・続柄・承諾と その 文・場所の 指示・文字の 指示・電話希望・原稿の 版（rev）と ハッシュ（sha256）・最後まで 見た 日時・IP・端末・ファイル（mark.jpg＝原稿に 印、photo_N.jpg）
- 電話番号は 保存しない（伏せ字と 下 4 桁だけ）。下 4 桁を 10 回 まちがえると 止まる（店に 電話）
- 期限（既定 30 日、create の `days`）を 過ぎると 開けない

## さくらへの 置き方
`kakunin-portal/` の 中身を そのまま `www/kakunin/` に 置く（`.htaccess`・`.user.ini`・`data/.htaccess` も。名前が「.」で 始まる ファイルは FTP ソフトで 隠れて 見えない ことが あるので、「隠しファイルを 表示」に して 確かめる）。
`README.md`・`.gitignore` は 置かなくて よい。

1. `www/kakunin/` に `index.html`・`api.php`・`upload.php`・`lib.php`・`.htaccess`・`.user.ini`、`data/` フォルダーと `data/.htaccess` を 置く
2. `.htsecret` を 作る（長い ランダムな 文字列 1 行。外注ポータルとは 別の ものに する）
3. `robots.txt` に `Disallow: /kakunin/`
4. ブラウザで `https://<ドメイン>/kakunin/upload.php` を 開き、`{"ok":true,"service":"kakunin-upload"…}` が 出れば 設置 完了
5. `https://<ドメイン>/kakunin/data/` を 開いて 403 に なる ことを 確かめる
